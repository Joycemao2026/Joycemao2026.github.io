# 毛小娟 Joyce · 个人介绍页

一个纯静态的个人介绍单页:固定的自我介绍 + 持续滚动更新的轻咨询案例。
没有框架、没有构建步骤,整个项目就是 `index.html` + `assets/` 两样东西,双击 `index.html` 就能在本地预览。

## 怎么改内容(不需要懂代码)

用任何文本编辑器(甚至 GitHub 网页上的铅笔按钮)打开 `index.html`:

### 加一个新案例
1. 搜索「**案例卡片模板**」,找到那段被 `<!-- -->` 包住的模板;
2. 复制注释**里面**的整段 `<article class="case">…</article>`;
3. 粘贴到案例列表的**最末尾**(按时间正序,最新的在最下面);
4. 改期数、标签、标题和描述;
5. 同步把「数据带」里 `03 期` 的数字 +1。

### 换照片
替换 `assets/photo.jpg`(竖版人像)。圆框里取景位置不对时,搜索 `object-position`,微调第二个百分比:数值越小,画面越靠头顶。

### 换联系方式
个人微信二维码 = 替换 `assets/wechat-qr.jpg`(只裁二维码本体,四周保留一圈窄白边,别带头像和文字);名片 = 替换 `assets/card.jpg`(信息面,公众号二维码在名片上)。文件名不变的话,页面代码不用动。

## 怎么部署(发布成公开链接)

1. 注册/登录 GitHub,把本项目建成一个**公开仓库**(名字建议 `intro` 或 `joyce`);
2. 仓库 **Settings → Pages → Branch 选 `main` → Save**;
3. 一两分钟后得到公开链接 `https://<用户名>.github.io/<仓库名>/`,微信里直接发这个链接即可;
4. 以后每次在 GitHub 上编辑并 Commit,线上页面约 1 分钟自动更新,**链接永远不变**。

## 想做一个自己的?

本仓库是模板仓库:点仓库首页的 **Use this template → Create a new repository**,即可复制一份到你自己的账号,替换文字、照片和 logo,再按上面的步骤开 Pages,就有了你自己的介绍页。

## 交接给下一个人

- 内容维护:对方只需要会「改文字、传图片、点保存」,把本 README 发给对方即可;
- 整体移交:仓库 **Settings → General → Transfer ownership**,把仓库转到新账号名下,原链接会自动跳转;
- 兜底:把整个文件夹发给任何懂一点网页的人,都能在十分钟内恢复部署。

## 文件结构

```

assets/photo.jpg               人像照片(网页用,已压缩)
assets/logo.jpg                New Moon 月牙 logo
assets/wechat-qr.jpg           个人微信二维码(纯码体)
assets/card.jpg                名片信息面(含公众号二维码)
```
